# First2DGame

Unity 2D game project for a two-person PC game.

## Development environment

- Unity: 6000.6.0f1
- Target: PC

## Team workflow

1. Pull the latest `main` before starting work.
2. Create a short-lived feature branch for each task.
3. Open a pull request or review the changes before merging into `main`.
4. Do not commit `Library`, `Temp`, `Logs`, `Build`, or `UserSettings`.
